# ClimbMe mobile navigation and Log runtime evidence

Viewport: synthetic `390 × 844` browser viewport
Runtime: isolated local Docker Compose project `climbme_mobile_ux`
Data: one fresh, synthetic private account and one synthetic climbing attempt

The scenario registers a new account, opens the Log section, completes the
existing required attempt fields and saves one attempt. It then uses the visible
mobile bottom tabs to reach Routes, Training and Insights, and returns to the
recent-attempt Log. This is local browser evidence only: it does not claim a
physical iPhone/Safari test, production deployment or real-user evidence.
