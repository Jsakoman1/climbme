# ClimbMe mobile Insights runtime evidence

Viewport: synthetic `390 × 844` browser viewport
Runtime: isolated local Docker Compose project `climbme_mobile_ux`
Data: one fresh, synthetic private account and one synthetic sent attempt

The scenario opens Insights from the mobile bottom tab bar and reads existing
private performance output: a KPI, grade-progression chart and a derived
achievement. It also checks that the document does not exceed the synthetic
viewport width. This is local browser evidence only: it does not claim physical
iPhone/Safari coverage, new metric semantics, coaching behavior or a public
release.
